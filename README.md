# ChatGPT Clone 🚀

A full-stack ChatGPT clone featuring user authentication, interactive AI-powered text chat, and persistent chat history.

---

## 🌟 Key Features

- **User Authentication:**
  - Secure User Registration & Login.
  - Session management and protected API endpoints.
- **Interactive AI Chat:**
  - Real-time text-based prompt and response interface modeled after ChatGPT.
  - Conversational AI capabilities answering a wide range of user questions.
- **Persistent Chat History:**
  - Automatically saves user conversations to the backend/database.
  - Allows users to review, load, and continue previous chat sessions.
- **Responsive Design:**
  - Modern, dark-mode friendly UI optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack

### Frontend

- **Framework/Library:** React / Vite (or Next.js)
- **Styling:** CSS Modules / Tailwind CSS
- **Icons & UI:** Lucide React / FontAwesome

### Backend

- **Runtime/Framework:** Node.js & Express
- **Database:** Mysql
- **AI Integration:** OpenAI API (or Gemini API / Custom LLM service)
- **Authentication:** JSON Web Tokens (JWT) / Cookies

---

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (v18+ recommended)
- [Git](https://git-scm.com/)
- Database instance (e.g., MongoDB URI, Supabase credentials, etc.)
- OpenAI / AI Service API Key
